# Training Data Catalog

Resources available for Aya → Aetheris distillation and post-conversion training.

## 1. Pre-training / Continual Pre-training

### NVIDIA ClimbMix (Primary)
- **Size**: ~400B tokens
- **Source**: HuggingFace `nvidia/ClimbMix`
- **Format**: Pre-tokenized (GPT-2 BPE), parquet shards
- **Languages**: Primarily English
- **Notes**: CLIMB-filtered web data. Outperforms FineWeb-Edu on downstream benchmarks. Pre-tokenized with GPT-2 vocab — our pipeline supports retokenizing to Aya's 256k vocab.
- **Script**: `scripts/run_climbmix_distill.py`, loader at `distill/climbmix.py`
- **Config**: `configs/distill_climbmix.yaml`

### FineWeb-Edu
- **Size**: ~1.3T tokens (full), ~100B filtered
- **Source**: HuggingFace `HuggingFaceFW/fineweb-edu`
- **Format**: Parquet, streaming
- **Languages**: English
- **Notes**: Education-quality web text. Good for English-heavy runs. ClimbMix generally preferred.

### CulturaX
- **Size**: ~6.3T tokens across 167 languages
- **Source**: HuggingFace `uonlp/CulturaX`
- **Format**: Parquet, streaming per language
- **Languages**: 167 languages including all 10 target languages
- **Notes**: mC4 + OSCAR deduplicated. Best multilingual pre-training resource. Use language-specific subsets for balanced training.

### MADLAD-400
- **Size**: ~250B tokens
- **Source**: Google, HuggingFace `allenai/MADLAD-400`
- **Format**: JSONL
- **Languages**: 419 languages
- **Notes**: Massive multilingual web crawl. Very broad coverage but noisier than CulturaX.

## 2. Instruction Tuning / SFT

### Aya Collection (Primary)
- **Size**: ~513M instances
- **Source**: HuggingFace `CohereForAI/aya_collection`
- **Format**: JSONL
- **Languages**: 114 languages
- **Notes**: The official Aya instruction dataset. Covers all 10 target languages. Templates, translations, and human annotations.

### Aya Dataset (Human-annotated subset)
- **Size**: ~204k instances
- **Source**: HuggingFace `CohereForAI/aya_dataset`
- **Format**: JSONL
- **Languages**: 65 languages
- **Notes**: Human-curated subset. Higher quality, smaller scale. Good for final SFT stage.

### Aya Evaluation Suite
- **Size**: ~26k instances
- **Source**: HuggingFace `CohereForAI/aya_evaluation_suite`
- **Format**: JSONL
- **Languages**: 101 languages
- **Notes**: Held-out eval set. Do NOT use for training.

### Self-Generated SFT Data
- **Size**: Variable (generated on demand)
- **Source**: Local, generated by `scripts/generate_training_data.py`
- **Format**: JSONL per language
- **Languages**: All 10 target languages
- **Notes**: Uses Aya teacher model to generate QA, math, reasoning, and tool-calling examples. Quality depends on teacher. Good for task-specific distillation.

## Recommended Data Mix

### Stage 1: Layer Alignment
No data needed for weight_map strategy. For distillation, use a small subset (~10k examples) from Aya Collection.

### Stage 2: KL Distillation
- **Primary**: ClimbMix (streaming, ~50k steps)
- **Multilingual supplement**: CulturaX subsets for target languages
- **Ratio**: 70% ClimbMix + 30% CulturaX multilingual

### Stage 3: SFT
- **Primary**: Aya Collection (filtered to 10 target languages)
- **Supplement**: Self-generated SFT data
- **Ratio**: 80% Aya Collection + 20% self-generated

### Post-Training
- Aya Dataset (human-annotated) for final polish
- Evaluate on mGSM + XCOPA throughout
